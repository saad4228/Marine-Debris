B. DERIVED ACOUSTIC & GEOSPATIAL TELEMETRY:
   When an image/tile is submitted to `POST /api/v1/detect`, the YOLO detector
   does not just output 2D bounding boxes; it computes side-scan sonar physics:
   - Port/Starboard Side: Evaluated based on bounding box center relative to
     the sonar nadir (centerline).
   - Slant Range & Ground Range (m): Derived from swath geometry (default 60m).
   - Water Depth (m): Towfish depth estimation.
   - Acoustic Shadow Length & Target Height (m): Shadow length calculated from
     bounding box aspect ratio; object elevation off seabed estimated using
     the acoustic shadow formula: H = (Hs * L_shadow) / (R_slant + L_shadow).
   - Georeferencing (Lat/Lon): Coordinates projected from survey vehicle base
     GPS position with slant range and heading offsets.

5. COMPLETE API ROUTE DIRECTORY
--------------------------------------------------------------------------------
The following endpoints are implemented and mounted under `/api/v1`:

A. Detection & Inference:
   - POST `/api/v1/detect`
     Accepts image file upload + optional query parameters:
     `survey_id`, `towfish_depth_m`, `swath_range_m`, `base_lat`, `base_lon`,
     `heading_deg`.
     Returns real YOLO detections with bounding boxes and computed telemetry.

B. Detection Catalogue & Management:
   - GET `/api/v1/detections` — List all detections with pagination & filtering.
   - GET `/api/v1/detections/{id}` — Get single detection details.
   - PATCH `/api/v1/detections/{id}` — Update detection (status, class, notes).
   - POST `/api/v1/detections/{id}/review` — Submit expert human review.

C. Survey Management:
   - POST `/api/v1/surveys` — Create a new survey record.
   - GET `/api/v1/surveys` — List all surveys.
   - GET `/api/v1/surveys/{id}` — Get detailed survey data + associated detections.

D. Statistics & Dashboard:
   - GET `/api/v1/stats/overview` — Aggregated counts by class, status, review.

E. Data Export:
   - GET `/api/v1/exports/csv` — Export detection catalogue as CSV.
   - GET `/api/v1/exports/geojson` — Export detections as geospatial GeoJSON points.
